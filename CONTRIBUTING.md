# Contributing to Trackwise

Read **[docs/WORKFLOW.md](docs/WORKFLOW.md)** before opening your first pull request — it's the
short version of how we ship: an owner-approved Trackwise task, a `feature/` branch off
`staging`, a reviewed PR into `staging`, verification on the staging environment, then a release
PR `staging` → `main` to reach production.

Conventions live in `AGENTS.md`; build decisions in `docs/PLAN.md`; production ops in
`docs/RUNBOOK.md`.
